📊 Game Player Analytics Dashboard

An interactive data analytics dashboard built using Python and Streamlit to analyze player performance, engagement trends, and game statistics through clear and meaningful visualizations.

This project demonstrates how raw game data can be transformed into actionable insights using data analysis and visualization techniques.

🚀 Features

📈 Interactive performance charts

🎯 Player score analysis

🌍 Country-based filtering

📊 Score distribution insights

⚡ Real-time dashboard interface

🧮 Key performance metrics display

🛠 Tech Stack

Python

Pandas

Matplotlib

Streamlit
